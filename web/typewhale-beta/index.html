先把边界说清楚。

它会上传我的语音吗?

不会。录音和识别都在本机完成,历史记录也只存在本机。默认的智能整理和翻译走本机 Ollama;只有你主动把整理模型切换为 DeepSeek 并配置 API Key,对应文本才会发送给 DeepSeek。

为什么 macOS 会提示"无法验证开发者"?

测试包尚未完成 Developer ID 公证。如果你信任这个包,可以在 系统设置 → 隐私与安全性 里允许打开。正式发行版会完成签名与公证。

付款后我买到什么?

当前 macOS Beta 的使用权、正式个人版上线后的继续使用权、1 年内个人版更新,以及优先反馈通道。早鸟买到的不是承诺,是参与一个正在成型的真实工具。
