# TypeWhale Pro 设计与交互规范

更新：2026-10-06。维护：UI 实施者与独立设计复核人。适用基线见 [入口](README.md)。

2026-09-11 声音体验回退：因高内存和系统卡顿撤回 MeloTTS 自然中文入口，声音页与 OpenClaw 恢复 Build 895 的 ZipVoice 选择和播放方式。保留原有音量、语速、个人声音、停止与取消路径；不以隐藏选项代替移除后台预热。Melo 暂停接入，实际界面与剩余验证见 [开发日志](DEVELOPMENT_LOG.md)。

## 产品意义

界面首先让用户确信正在录音、文本不会丢、操作能取消、结果会回到正确位置。主窗口是原生桌面工作台，胶囊是低打扰的输入反馈，截图浮层是观察与编辑工具。

历史用户反馈明确要求保住过去胶囊的连续感。本文件整理规则，不宣称完成了 Build 895 的全屏幕视觉验收，也不授权更换当前主题或动画。

## 主窗口与信息层级

- 当前任务、模型与权限状态必须可读；次级诊断、版本历史、测试入口不压过主流程。
- 控件溢出要重组或放入合适的滚动／弹窗，不能靠缩小到难以点击来解决。
- 设置标题、状态说明和实际行为一致。例如媒体暂停必须解释为恢复“本次由应用暂停的内容”。
- 长模型名、中文、长快捷键和较长错误提示不能遮挡邻近控件；空列表、加载、失败与恢复状态均应设计。
- 优先使用共享样式与系统控件、系统字体，不引入未经授权的字体。

旧 [三栏像素预算](../../DESIGN.md) 和 [方案 C](../design/concept-c/README.md) 是历史参考。本轮没有重新量测安装版，不把旧 1080×640、颜色或列宽重新宣布为当前硬约束。后续布局改动先核对 [现有主窗口实现](../../native/Sources/Presentation/Main/) 与真实截图，再记录更新后的尺寸证据。

## 本地整理模型检测

- 检测入口内联在“模型”页的“整理模型”卡片，保留下拉框和原说明；诊断是次级能力，不另开弹窗，也不压过模型选择。
- 初始状态明确写“尚未检测”；运行中依次显示检查环境、校验文件、加载模型、验证生成，按钮显示“检测中”并禁用，主窗口其他控件继续可用。
- 成功同时使用“本地模型正常”文字和成功色，显示总耗时及可用指标；真实失败同时使用“本地模型不可用”文字、失败阶段、错误码、建议和错误色。`runtime_busy`／重复检测属于暂时状态，使用橙色“暂时无法检测”，不得误报模型损坏。颜色不得成为唯一信息。
- “复制诊断”仅在检测得到报告后出现；复制是用户显式动作，反馈为按钮“已复制”，文案说明诊断不含录音、转录、提示词和密钥。
- 状态和详情分别最多两至三行、按词换行；长动态库错误只进入复制诊断，不能撑坏卡片。开始／复制按钮均使用原生小号圆角样式和独立 VoiceOver 标签；阶段和最终状态变化发送可访问性值变更通知。

## 胶囊与动效

- 显示与隐藏不抢输入焦点；录音反馈及时，等待、结束、失败和取消必须能够区分。
- 稳定文字不能因分块重置而反复跳变；显示后缀裁剪不改变完整内容。
- 改动前先查历史退化机制；不能为去掉闪烁而直接删掉原有过渡或上下文。
- 独立概念画廊位于 [Helpers](../../native/Helpers/CapsuleConceptGallery/)，不属于安装版生产 UI。演示通过不等于产品通过。
- 检查连续录音、长句、快速取消再启动、多屏边缘、缩放和减少动态效果设置；未能覆盖时必须记录。

## 自动发送与截图

倒计时不阻塞粘贴与下一次录音；数字、取消入口、目标关系清晰。取消按钮、Esc 或鼠标右键的第一次操作必须有效，不能要求第二次；右键按下与抬起不得有一次穿透到前台应用。屏幕边缘也应能看见并操作。

截图进入不能无故唤醒主窗口。选区、工具栏、编辑、翻译等待、失败与取消应保持上下文；悬停／选择窗口造成的桌面变化要限于用户明确选择的必要范围。复制、保存、关闭后不得留下透明拦截层。

## 遥控器页面

- 原有连接、设备、语音链路、映射、权限和排障信息保持在图示之前；“设备与按键说明”必须位于滚动页最下方。
- 设备图只允许使用发行者独立取得公开分发授权的本地 RC003 产品图，授权与来源记录见 [第三方声明](../../THIRD_PARTY_NOTICES.md)；公开源码不附带该图，也不得在运行时联网加载。缺图时显示明确占位，13 个映射控件、状态与排障信息仍完整可用；授权版图示维持左六右七与既有折线布局。
- 每个标签显示“按钮名称 + 当前功能”，并随映射修改／恢复立即同步。13 键都可在当前安全目录内配置，语音键默认按住说话；动作菜单按默认、键盘、TypeWhale、Mac 与关闭分组，不提前展示尚未实现的扩展动作。
- 具备授权图片时，点击任一按键映射下拉框只高亮对应实体区域并显示最近识别的按键／当前动作；选择完成后可再次反馈，但页面预览不得执行真实动作。物理遥控器 down 立即高亮，up 后至少保留 180ms 可见反馈，缺失 up 时由现有输入保险复位。缺图时不得伪造可能误导用户的产品外观。
- 按钮名使用 11pt medium，功能使用 10pt muted；长文案优先获得布局空间，不能通过不可读缩字、裁切或横向滚动解决。
- 图形与连线是装饰层，不进入 VoiceOver 焦点；每个原生标签作为单一可访问元素读出“名称，当前功能”。颜色不得成为唯一映射或连接状态信息。
- 连线端点必须落在原图对应实体按键上，不遮盖标签或穿越相邻标注；图片缺失时显示明确占位，页面其余映射控件仍可使用。

## 可访问性与素材

- 颜色不是唯一状态信息；纯图标按钮提供 tooltip 和 accessibility label。
- 键盘焦点、Esc 取消和快捷键录入需可预测；系统正常按键不被无关状态吞掉。
- 字体使用系统 API；商业字体或第三方素材必须具备明确授权记录。
- 尊重系统减少动态效果；不能仅为演示效果强制动画。

## 设计验收门槛

| 检查 | 必需证据 | 不通过的表现 |
| --- | --- | --- |
| 主窗口 | 安装版截图，标明 build、屏幕、缩放及场景 | 裁切、遮挡、层级失衡、中文被截 |
| 胶囊 | 录屏或连续状态证据，包含自然停顿与收尾 | 闪烁、跳变、内容丢失、抢焦点 |
| 倒计时 | 第一次取消、手动发送、切换应用、新录音 | 双发、误发、取消不生效 |
| 截图浮层 | 进入、选择、编辑、复制／保存、Esc | 打乱桌面、残留浮层、停止语音 |
| 遥控器页 | 安装版顶部与滚动到底截图；深／浅主题、正常／窄宽度、修改／恢复映射及可访问性树 | 图示缺键、错连、交叉、截字、标签不同步、上半页退化或装饰抢焦点 |
| 复核 | 至少一次设计质量 review；可用时独立 reviewer | 只有作者自评或编译成功 |

Build 913 遥控器页继续使用准确 RC003 原图；生产组件快照覆盖深／浅、常规／窄宽、缺图及按键高亮，13 键映射／恢复／页面 preview 联动通过。安装版 Remote tab 核对 13 个控件和标签、动作菜单分组、滚动、可访问性及“刚刚识别”反馈；Build 904 的真实 RC003 日志继续作为 HID／F5 现场证据，本轮没有重新执行物理遥控器按键。
