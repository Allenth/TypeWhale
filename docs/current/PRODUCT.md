## 目标、场景与成功标准

为高频桌面输入者提供“说话 → 识别 → 可选整理／翻译 → 写回”的可靠工作流。优先服务口述需求、反馈、邮件和聊天的开发者、产品与办公用户。用户不用离开目标应用，能够理解正在发生什么，失败时知道如何找回结果。

P0 是识别与目标正确、不丢内容、不误发送、不抢焦点；P1 是自然表达、稳定预览、连续输入响应与可恢复配置；扩展能力不得以牺牲主链路为代价。体验退化必须追溯历史机制，不能通过删除已验证好体验来解释修复。

## 当前范围与非目标

| 能力 | 当前产品边界 |
| --- | --- |
| 语音输入 | 全局快捷键、麦克风、实时胶囊、选择本地 ASR、最近转录、目标写回；单次录音上限五分钟 |
| 智能文字 | 整理、语音翻译、截图 OCR 翻译共享用户选择的智能模型；模型页可显式检测受管 Qwen 的运行环境、文件、加载和最小生成，模型清单与默认迁移规则由 [架构](ARCHITECTURE.md) 维护 |
| 截图 | 区域／窗口选择、编辑、OCR、翻译、复制／保存／归档；截图不能停止正在进行的语音工作 |
| 闪念 | 独立整理模式与本地需求池／Markdown 归档，不用主输入模式替代其设置；未配置目录时使用当前用户的 `文稿/TypeWhale/需求池`，已有自定义目录保持不变 |
| 应用范围与发送 | 按目标应用配置；粘贴完成后独立倒计时，默认 2 秒、可设 1–10 秒；自动发送默认关闭 |
| 录音媒体控制 | 降音量与暂停媒体为独立设置；降音量目标为静音，暂停与恢复必须尊重播放状态与用户操作 |
| 小米遥控器 | 原生 RC003 连接与语音输入；遥控器页显示连接、语音链路、权限和 13 键映射。具备独立授权的本地发行版可附带产品图，公开源码默认显示缺图占位且不影响映射。13 键均可配置并记忆当前安全动作，默认值保留原行为；选用自定义动作时替代该键原系统事件 |
| OpenClaw／声音 | 已有代码接入的可选扩展；仍按实验边界验证，不作为普通输入依赖，不宣称已全面商业验收 |
| 模型与权限 | 下载、校验、选择、状态和权限诊断；模型未就绪要显式反馈 |

不承诺多小时会议转写、说话人分离、Windows 与 macOS 同步正式发行、云端笔记同步、企业授权、托管 AI 额度或自动执行口述任务。录屏设置、历史候选模型与概念胶囊不因存在设计文件就成为已交付功能。

## 核心旅程与验收

| 旅程 | 用户操作与预期 | 失败／边界验收 |
| --- | --- | --- |
| 首次输入 | 打开主窗口，完成权限与模型准备，在普通文本框触发绑定键，说一句话并结束；只写回一次 | 未授权、模型缺失必须可理解；无声录音不能制造成功结果 |
| 连续口述 | 自然停顿、继续说话，预览保持上下文，结束后得到完整文本；保持录音时切换另一输入，旧句先安全收尾再开启新句 | 胶囊截断显示不等于截断结果；前句不能因新分块或新输入会话消失；重复停止、迟到回调和五分钟上限均需验证 |
| Fn 与遥控器 | Fn 快速点按进入持续录音，按住超过 450ms 后松开结束；遥控器语音键按住说话 | 定时回调或蓝牙重复包不能改变手势／会话身份；遥控器语音键不能以 F5 污染前台文本框，物理 F5 与其他遥控器系统键必须保留 |
| 遥控器页面 | 进入“遥控器”，查看／调整 13 个键；语音键可在“按住说话”与其他安全动作间切换，返回键可选 Esc，电源键可选锁定 Mac；具备授权图片时反馈对应实体位置，公开源码缺图时显示明确占位；恢复默认后控件与图示同步 | 13 个映射不重不漏、当前功能不截断；缺图、断连时说明仍可读且控件可用；自定义映射须替代而非叠加原系统动作，物理键盘同名按键和未映射系统事件不能被吞 |
| 选择 ASR | 结果来自用户选择的模型；SenseVoice 可按设置复用完整缓存 | 非 SenseVoice 失败不允许偷偷换模型成功；详见架构中的权威规则 |
| 整理与翻译 | 原文模式不调用整理；整理改善表达但不代答；翻译按方向忠实转换，保持原文的陈述／疑问／命令类型和说话人立场 | “请帮我分析这个错误”作为待整理素材，不直接输出解决方案；“现在可以翻译成英文吗？”必须仍输出问句，不得先补“Yeah, sure”等回应；空结果或错误不得静默跨服务商 |
| 本地整理模型检测 | 在“模型 → 整理模型”点击“开始检测”，依次看到运行环境、模型文件、加载和最小生成状态；成功显示耗时，失败显示阶段、错误码与建议，可显式复制脱敏诊断 | 必须验证真实 `mlx_lm` 导入和固定最小生成；不切换当前模型、不调用云端、不抢占正式整理／翻译、不自动修改文件；诊断不得含录音、转录、提示词、生成正文或密钥；用户选择 Qwen 时同样须先通过后台运行时探针，失败保持原模型 |
| 自动发送 | 在测试应用设置发送动作，粘贴后才计时；调整时长按设置生效 | Esc、鼠标右键或取消按钮第一次操作即取消；切换应用、新录音、新任务后旧计时不补发；用户手动发送不导致二次发送；未倒计时时 Esc／右键保持原行为 |
| 截图 | 选区域／窗口，执行 OCR、翻译、复制、保存或归档 | Esc 取消后恢复；不能无故激活主窗口、打乱桌面顺序；窗口选择所需临时操作除外 |
| 闪念与历史 | 记录一条闪念并在需求池核对原文与模式；从最近转录复制结果 | 归档目标错误应提示；不以主模式覆盖闪念模式；找回内容不自动重发 |
| 连续录音音量 | 开启降低音量后连续录音，最后结束恢复首次基准 | 中间不恢复、不把静音记录为新基准；用户手调后不覆盖其选择 |
| 媒体暂停 | 开启后只暂停原本正在播放且可识别的媒体，并只恢复本次暂停的同一播放器 | 原本暂停不反向播放；未知状态、播放器变化、用户恢复时不补发切换 |
| OpenClaw | 使用显式绑定进入独立对话，看到等待／回复／失败；可选朗读 | 普通输入不误触发；对话不粘贴前台；Node 故障不阻塞主输入；朗读失败不隐藏文本 |

这些是可执行验收要求，本轮文档整理不构成上述路径已经全部实测通过。执行记录进入 [发布验收](RELEASE_QA.md) 与 [日志](DEVELOPMENT_LOG.md)。

## 不可退让的行为约束

- 主输入、OpenClaw、闪念、截图各自拥有任务身份；取消与回调不能跨任务生效。
- 录音采集与收尾任务不得共享可被下一次输入覆盖的隐式所有权；新录音可以在旧任务后台识别期间开始，但必须等旧任务完成音频与候选快照交接。
- 保留用户主观感受、约束、否定、顺序、例子与语言意图；不能把“只整理”变成问答代理。
- 翻译的自然语气与社交风格不得覆盖语义忠实性；原文没有的回应、确认、寒暄、语气前缀或新说话轮次都不能添加。
- 粘贴尊重原目标与剪贴板；目标失效不能把文本或发送按键交给另一个应用。
- 模型常用时保持热态，不增加空闲定时卸载；内存安全网不能作用于录音、识别、整理、粘贴中的任务。
- 本地模型检测只报告状态，不承担下载、重装或自动修复；共享 Worker 正忙时明确提示稍后再试，不能取消或排队阻塞用户任务。
- 本地优先不等于所有功能零联网。云端文字处理与 OpenClaw 数据边界必须清楚，见 [架构](ARCHITECTURE.md)。
