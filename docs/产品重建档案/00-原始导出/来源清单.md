## 完整性边界

- 本机记录不能证明云端、已删除设备或其他账号中的对话完整存在。
- Codex 的工具调用和内部推理不属于用户可见对话；人类可读导出会排除，但原始 JSONL 哈希用于追溯。
- 同一任务可能包含主会话、并行 agent 和续接记录，必须先去重再统计真实对话数量。
- 诊断附件、截图和录屏需要先检查隐私信息，再决定保存原件、脱敏副本或只保留哈希。
