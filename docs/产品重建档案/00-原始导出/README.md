## 可以放入的材料

- ChatGPT、Claude、Codex 等 AI 工具导出的完整对话。
- 用户最初提出功能时的原始提示词和后续追问。
- 与对话直接相关的截图、录屏说明、附件和手工记录。
- 无法直接导出的历史内容所对应的来源说明和缺失记录。

代码、Git 提交、现有产品文档和构建记录暂不复制到这里；后续建立证据索引时直接引用原路径和提交号，避免制造重复副本。

## 导入规则

1. 尽量保留原始文件格式、内容顺序和时间信息。
2. 不在原始导出中修正文案、删除失败讨论或补写当时没有出现的结论。
3. 同一对话分多次导出时标明先后顺序，不静默合并造成上下文错位。
4. 资料不完整时明确写“缺失”或“仅保留片段”，不能依据记忆补成原话。
5. 导入前检查密钥、账号、手机号、地址等敏感内容；仓库内只保留安全的脱敏副本。

## 建议命名

```text
YYYY-MM-DD_来源_主题_序号.扩展名
```

示例：

```text
2026-06-03_Claude_项目启动_01.md
2026-06-05_ChatGPT_全局快捷键讨论_01.html
日期不详_Codex_截图翻译片段_01.md
```

日期应使用材料本身能够证明的日期；无法确认时写“日期不详”，不要根据文件修改时间猜测对话日期。

## 每份材料的伴随信息

如果导出格式本身没有这些信息，在同名 Markdown 说明文件中补充：

```text
材料编号：
来源平台：
对话时间范围：
导出日期：
完整性：完整／部分／片段
关联功能：
脱敏情况：无／已脱敏（说明范围）
备注：
```

伴随信息用于描述来源，不得改写原始对话的含义。
