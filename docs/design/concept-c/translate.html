03 · 功能归位与开发对接

本页收拢了什么

翻译原本散在「智能」标签里。方案 C 把翻译相关全部收进本页,与整理彻底分家:

  • 自动翻译← 原「智能」开关
  • 翻译方向← 原「智能」下拉 → 改分段
  • 翻译提示词← 原「智能」拆成中/英两向
  • 社交清单← 原「智能」(它驱动中译英语气)

翻译方向由下拉改分段控件:仅三档,置顶高频,当前方向一眼可见,少一次点开菜单。
