02 · 连接状态

连接自检有三态,导航底部与页头状态芯片同步显示,颜色即语义。

已连接

网关可达、Agent 就绪。可正常语音对话,页头显示绿点。

检测中

正在握手网关与 CLI,琥珀色脉冲,通常一两秒内落定。

不可用

网关不可达或路径无效,给出具体原因与修复指引,不静默失败。

03 · 功能说明与开发对接

为什么独立成页

OpenClaw 是面向进阶用户的智能体接入,配置项(四字段 + 自检)与语音输入完全不同维度。挤进标签栏会稀释主流程;独立成导航页,既不打扰普通用户,又给需要它的人一个清晰的家。

这正是方案 C 的长线价值:高级/可选功能各占一格导航,主流程不被它们撑胖。
