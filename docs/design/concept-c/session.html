03 · 设计 token 与开发对接

配色 token 映射

现有 UITheme.waterInk* 是深色版;晨雾微光是同族的浅色版,直接改这些 token 的值即可,组件代码不动。

Token晨雾取值用途
waterInkBackground#EBEFF3窗口底
waterInkSurface#FFFFFF卡片面
waterInkPanel / panelFill#F5F8FA导航栏/次级面
waterInkLine / cardBorderrgba(64,94,116,.15)描边
waterInkText#2C3E4B主文字
waterInkMuted#6E8290次要文字
waterInkFaint#94A6B2弱化/占位
waterInkMistBlue / capsuleAccent#5B84A6强调/选中/波形
waterInkSuccess#5AA588完成态 LED
waterInkWarning#C0975B识别中态
新增 waterInkRecording#D08A72录音态 LED

规格

  • 导航宽172pt 固定,项高 34pt,圆角 10pt,选中态雾蓝填充白字
  • 内容内边距22 / 26pt,分区间距 18pt
  • 卡片圆角 16pt,描边 1px,内边距 20pt
  • 字号状态 21 / 标题 22(宋体)· 正文 14.5 · 次要 11.5 · 标签 9.5(大写字距)
  • LED12pt 圆点 + 5pt 同色光晕,颜色即状态语义
  • 波形描边 2.2px 圆头,雾蓝;录音/识别态随语义色变

代码对接点

  • 配色 token
    Presentation/Shared/UIComponents.swift · UITheme
  • 会话卡 / 状态区
    MainViewController+PanelLayout.swift · buildSessionPanel
  • 最近转录列表
    MainViewController+RecentTranscriptions.swift
  • 左导航壳（新增）
    替换 buildInspectorTabs 的标签栏为侧导航
