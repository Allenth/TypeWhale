03 · 功能重组与开发对接

相比现状:哪些搬走了

现在「智能」标签把整理 + 翻译 + 闪念 + 归档挤成 13 行。方案 C 按归属拆分,本页只留整理本身:

  • 自动翻译→ 迁往 翻译 页
  • 翻译方向→ 迁往 翻译 页
  • 翻译提示词→ 迁往 翻译 页
  • 社交清单→ 迁往 翻译 页(驱动中译英语气)
  • 闪念整理→ 迁往 闪念 页
  • 归档整理→ 迁往 截图 页

拆分后本页从 13 行降到 7 项,分 3 组卡片。这正是选方案 C 的理由:功能各归其位,单页不再臃肿。
