# 生产胶囊清晰边缘修复设计

日期：2026-08-03

## 问题与根因

闪念与 OpenClaw 生产胶囊的强调边框存在模糊、脏边和圆角残影。当前 `RecordingCapsuleView` 沿胶囊 body 的同一路径先绘制 `4.5px`、35% 透明度的宽描边，再叠加 `1.8px` 实色描边。宽描边以路径为中心向内外各扩散约 `2.25px`，外半部分进入透明 panel 边缘并与毛玻璃抗锯齿混合，形成截图中的模糊外圈。

`RecordingPanel` 的毛玻璃使用 `UITheme.capsuleCornerRadius = 21`，而生产胶囊 shell 使用 `20`。两个相邻图层的圆角不一致会让透明背景上的角部残影更加明显，OpenClaw 外置徽章预留空间下尤其容易观察到。

## 目标行为

- 闪念、OpenClaw、倒计时和内存警告的强调边框均保持清晰、稳定的实色轮廓。
- 柔和状态氛围只向胶囊内部延伸，不再越过 body 边界进入透明窗口区域。
- 毛玻璃背景与胶囊 body 使用同一个圆角事实源。
- 普通胶囊默认边框、闪念淡紫内光、OpenClaw 红色内光、波形、文字、顶部信息条、徽章位置、胶囊尺寸和动画节奏保持不变。

## 绘制设计

强调边框改为两条彼此分离的路径：

1. 外轮廓沿现有 body path 绘制约 `1.6–1.8px` 实色描边，负责清晰边界。
2. 柔光路径向内 inset 后绘制低透明度宽描边，使整个宽描边都落在胶囊内部。内向柔光不得触碰 panel 外部透明像素。

柔光继续使用对应状态颜色，不增加 shadow、滤镜、离屏模糊或新的动画。这样保留特殊状态识别，同时避免外扩散和裁切。

毛玻璃 `NSVisualEffectView` 的 `cornerRadius` 改为使用 `MainCapsuleShell.cornerRadius` 暴露的共享常量，避免 `20/21` 双事实源。OpenClaw 的 `materialFrame`、body rect 和徽章 overhang 计算保持不变。

## 测试与验证

- 增加纯绘制/像素回归：强调边框外侧采样区不得出现状态色像素；边界与内部采样区必须保留可见状态色。
- 闪念与 OpenClaw 至少各覆盖一张离屏渲染图，防止只修一种颜色。
- 继续运行 `RecordingCapsuleOpenClawGlowCheck`、主胶囊 shell/panel shell 检查及现有闪念内光回归。
- 构建安装版后分别触发闪念和 OpenClaw 胶囊，截图检查静止边缘、圆角、徽章交叠和毛玻璃裁切。
- 若无法自动触发某一真实状态，必须明确记录未验证风险，不得用源码推断代替安装版结论。

## 验收标准

1. 用户截图标记的左上、左下和圆角位置不再出现扩散脏边或矩形残影。
2. 闪念蓝边和 OpenClaw 红边均有清楚的一条外轮廓，内部仍有柔和色彩氛围。
3. 动画期间轮廓不闪烁、不跳粗细、不因 resize 短暂露出其他颜色边框。
4. OpenClaw 小龙虾徽章继续位于胶囊右上外层，透明间隔与主体尺寸不变。
5. 普通录音、预览文字、波形和最终语音链路行为不变。

## 范围边界

本轮只修改已跟踪的生产胶囊绘制、共享圆角和对应测试。不得修改、格式化、构建接入或提交当前未跟踪的 `native/Sources/Presentation/Capsule/Concepts/` 与 `native/Helpers/CapsuleConceptGallery/`。
