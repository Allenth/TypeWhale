# Overlap Correction Setting Design

## Goal

把现有重叠校正能力作为正式产品功能提供设置入口，名称统一为“重叠矫正”，供用户对照测试分块边界处的丢字、重复字和错拼改善效果。

## Product Placement

- 页面：控制面板 → 常用 → 录音与预览。
- 位置：紧跟“胶囊实时预览”。
- 名称：`重叠矫正`。
- 不放入“诊断工具（实验）”。
- 不显示现有“长录音增量输出（实验）”开关。

## Behavior

- 复用现有 `correctedPreviewExperiment` 控件、`experimentalCorrectedPreview` 设置键和保存/读取逻辑，不新增第二份设置。
- 本轮默认值保持关闭，便于同一安装版中进行关闭/开启对照。
- 当前 ASR 模型不支持该能力时，开关不可操作；切换到支持的模型后恢复。
- 打开后，新录音会进入现有重叠校正路径；关闭后，新录音继续使用普通生产快照路径。
- 录音过程中修改设置不改变已经开始的会话，只影响下一次录音。

## Copy

- 标题：`重叠矫正`
- 提示：`在分段处重新识别前后音频，减少丢字、重复字和错拼。`
- 可访问性名称同步改为 `重叠矫正`，不得保留“实验”文案。

## Boundaries

- 本轮只新增正式设置入口和文案，不修改重叠校正算法。
- 不修改 1.2 秒短句收口、18 秒硬边界、Final ASR 或最终交付来源。
- 不默认开启；真实录音测试通过后再单独决定是否默认开启。
- 如果测试证明整体效果变差，再单独删除该功能和遗留设置，不在本轮预判删除。

## Acceptance

- “录音与预览”分区能看到“重叠矫正”开关。
- 开关选中状态清晰，保存后重启 App 状态不丢失。
- SenseVoice 下可操作；不支持的模型下不可操作。
- 开关关闭时走普通快照；打开时走现有校正路径。
- 设置页不出现“重叠校正预览（实验）”或“长录音增量输出（实验）”。
- 其他设置的顺序、分区和功能不变。

## Validation

- 自动测试锁定布局、正式文案、旧设置键复用和能力门控。
- 构建安装后检查真实设置页布局、开关选中效果与重启持久化。
- 分别关闭/打开开关，使用相同短句、停顿续说和 18 秒连续语音进行对照。
