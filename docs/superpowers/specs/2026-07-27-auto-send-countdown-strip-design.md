# 自动发送倒计时整条取消设计

## 目标

自动发送进入 2 秒倒计时后，不再显示独立“取消”按钮。倒计时条本身就是完整的取消
目标，用户点击任意位置都只取消追加按键，已经粘贴的文字保持不变。

## 用户可见结果

- 倒计时条只显示居中的剩余时间，不显示按钮或分隔线。
- 整条均可点击，第一次点击立即取消。
- 倒计时条的中心点与主胶囊中心点完全重合，横向、纵向都居中覆盖。
- 用户提前按 Return 或数字键盘 Enter 时，现有倒计时同步取消，不再二次发送。

## 边界

- 只修改 Presenter 的视觉与鼠标命中范围，不修改 Coordinator、计时长度、目标应用
  复核、Esc、Return 门禁、粘贴或发送状态机。
- 保持非激活浮层，不抢走目标应用焦点。
- 为整条保留“取消自动发送”的辅助功能按钮语义和键盘辅助操作。

## 验收

1. 触发自动发送后，只看到 `2.0 秒后发送`，没有“取消”按钮和分隔线。
2. 点击倒计时文字、左右留白任意位置都能取消，文字仍保留。
3. 倒计时条与胶囊横向、纵向中心都一致，胶囊移动后下一次仍正确对齐。
4. 不点击时只发送一次；提前按 Enter 时也只发送一次。
5. Esc、切换应用、新录音取消和自然到期继续正常。
