# 自动发送倒计时与取消设计

**状态：** 已批准，待实施
**日期：** 2026-07-24
**关联功能：** 应用范围与粘贴后自动发送

## 1. 目标

当普通听写为当前应用配置了“回车”或 `Command + 回车` 时，文字先正常粘贴，
随后显示 1.5 秒倒计时。用户可以在倒计时结束前点击“取消”或按 `Esc`，
只取消追加按键，已粘贴文字保持不变。

## 2. 范围

### 包含

- 固定 1.5 秒倒计时，不新增时长设置。
- 独立小浮层显示剩余时间和“取消”按钮。
- 点击“取消”或按 `Esc` 取消本次发送。
- 目标应用切换、新录音开始、应用退出时自动取消。
- 倒计时结束时重新确认目标应用仍在前台，再发送已确定的按键。
- 记录开始、取消、跳过和实际发送的诊断日志。

### 不包含

- 不撤销、不修改已粘贴文字。
- 不修改 ASR、实时缓存、Final ASR、整理提示词或任何胶囊。
- 不作用于翻译、闪念、OpenClaw、手动复制和未配置应用。
- 不把倒计时逻辑放进浮层或胶囊 UI。
- 不允许多条倒计时并存或跨任务发送。

## 3. 已选方案

采用独立倒计时控制器。对比方案：

1. 复用主胶囊：依赖胶囊开关和生命周期，不采用。
2. 在粘贴队列中直接等待：会阻塞后续粘贴请求，不采用。
3. 独立控制器管理延迟、取消和目标校验，浮层只展示状态：采用。

## 4. 交互

- 浮层文案：`1.5 秒后发送`，右侧提供“取消”。
- 倒计时应平滑更新，显示到一位小数；不要求每 0.1 秒触发业务判断。
- 浮层不抢输入焦点，不改变当前前台应用。
- `Esc` 只在倒计时存在时拦截，并只取消当前倒计时；没有倒计时时保持系统原行为。
- 取消后浮层立即消失，不弹确认框。
- 倒计时自然结束、自动取消或手动取消后，必须释放按键监听和计时资源。

## 5. 分层与数据流

```text
PasteCoordinator 确认文字粘贴事件已发出
→ AutoSendCountdownCoordinator 创建唯一 PendingAction
→ AutoSendCountdownPresenter 显示倒计时（只展示）
→ 用户取消 / Esc / 新录音 / 目标切换 / 1.5 秒到期
→ Coordinator 仲裁
→ 到期且目标仍正确：PostPasteKeyEmitter 发送按键
→ 其他结果：只清理倒计时，不影响已粘贴文字
```

### 责任边界

- `PasteCoordinator` 只提交已确定的动作、目标应用和任务标识，不持有 UI。
- `AutoSendCountdownCoordinator` 是倒计时状态的唯一所有者，负责替换、取消和到期仲裁。
- `AutoSendCountdownPresenter` 只接收展示快照并上报取消意图，不决定是否发送。
- `PostPasteKeyEmitter` 继续只发送按键，不感知倒计时和 UI。
- `SpeechInputCoordinator` 只在新录音开始时通知取消，不管理计时器。

## 6. 状态与规则

状态只有：

```text
idle → countingDown → emitted
                   ↘ cancelled
                   ↘ skipped
```

- 新任务到来时，先取消旧的 `countingDown`，再建立新任务。
- `cancelled`：用户点击取消、按 `Esc`、新录音开始或应用退出。
- `skipped`：倒计时结束时目标应用已变化，或按键事件无法创建。
- 每个 PendingAction 包含唯一 token、任务标识、目标 PID/Bundle ID、动作和截止时间。
- 任何旧 token 的延迟回调都不得影响新任务。

## 7. 验收标准

1. 配置自动回车后，文字先粘贴，浮层随后出现并显示约 1.5 秒倒计时。
2. 点击“取消”后不发送按键，文字仍在。
3. 倒计时期间按 `Esc`，结果与点击取消一致。
4. 不取消且目标应用未变，1.5 秒后只发送一次配置按键。
5. 倒计时期间切换应用，不向新旧应用发送按键。
6. 倒计时期间开始下一次录音，旧发送被取消。
7. 连续产生两个自动发送任务，只允许最新任务倒计时，旧任务永不补发。
8. 翻译、闪念、OpenClaw、未配置应用不显示倒计时。
9. 浮层不抢焦点，用户可以继续编辑已粘贴内容。
10. 取消、跳过和事件创建失败不阻塞下一次粘贴。

## 8. 测试与发布边界

- 单元测试覆盖倒计时到期、两种取消、任务替换、旧 token、目标切换和只发送一次。
- 边界测试确保 Presentation 不发送按键，Emitter 不依赖 UI，倒计时不阻塞粘贴队列。
- 真实安装版验证点击取消、`Esc`、回车、`Command + 回车`、切换应用和连续任务。
- UI 改动必须使用 `design-review` 检查浮层位置、可读性、焦点、闪烁和消失节奏。
- 自动发送总开关仍是总回滚入口；关闭后不得创建倒计时。

## 9. 开发边界

- In scope：倒计时领域状态、协调器、浮层、取消监听、现有自动发送接入、测试和文档。
- Out of scope：应用范围页面改版、时长设置、撤销粘贴、语音链路调整。
- Do not touch：ASR、VAD、实时预览缓存、主胶囊/旁路胶囊、智能整理、翻译结果生成。
- P0：取消绝不能删除文字；切换应用绝不能误发；旧倒计时绝不能晚到发送。
