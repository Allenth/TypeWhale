# Short-Utterance Pause Finalization Design

## Goal

短句说完后，停顿满 1.2 秒即完成一次收口识别并锁定文本，避免当前路径继续把新增静音加入同一快照、每 0.5 秒重识别整句，导致正确短句被反复改坏。

## Current Problem

普通实时路径从 0.3 秒开始、此后约每 0.5 秒识别一次“当前块开头到现在”的全部音频。10 秒前整块文本都属于可修改尾巴。短句说完后，系统仍会把不断增长的静音送进 ASR，新结果只要通过基础过滤就会替换整句，最后锁定的是最后一次结果，而不是语音结束附近的可靠结果。

## Product Behavior

1. 有人声时，保持现有实时预览节奏。
2. 检测到停顿后，不再发送包含更长静音的普通实时快照；胶囊保持最后一份可用文字。
3. 停顿连续达到 1.2 秒时，对本次语音段执行一次收口识别。
4. 收口音频保留少量语音前后缓冲，但不携带无界增长的长静音。
5. 收口结果有效时锁定；收口失败、为空或明显异常时，保留停顿前最后一份可用结果。
6. 锁定后开始新块；后续说话作为下一段识别。

## Architecture

- `AudioRecorder` 负责根据现有 Silero VAD 状态识别连续 1.2 秒停顿，并产出一次 `isChunkFinal` 快照。
- `SpeechInputCoordinator` 继续负责识别队列和块顺序，不在 UI 中判断或修正文本。
- `applyRealtimePreview` 只把有效收口结果冻结进 `committedPreviewText`；失败时冻结已有 `latestPreviewText`。
- `ProductionRealtimePreviewDeliveryCache`、主胶囊和最终粘贴继续消费同一个生产快照，不新增缓存。

## Boundaries

### In Scope

- 普通本地实时快照路径。
- 1.2 秒停顿收口。
- 停顿后的重复识别抑制。
- 收口失败保留已有文本。

### Out Of Scope

- 18 秒强制分段的前后重叠校准。
- 校准实验路径内部算法。
- 候选/旁路胶囊定位与 UI。
- Final ASR 开关和最终交付仲裁。
- 针对具体错词的硬编码替换。

## Failure Handling

- VAD 不可用：保留现有 10 秒软边界、18 秒硬边界行为。
- 收口 ASR 超时或失败：冻结停顿前最后一份有效文本，不能清空。
- 停顿不足 1.2 秒又继续说话：取消本次停顿收口，继续当前块。
- 收口进行时的新音频必须进入下一块或排队，不得丢失。

## Acceptance

- 说 2–6 个中文字后停顿 1.2 秒，文字最多在收口时更新一次，随后不再反复变化。
- 停顿 2–5 秒后继续说第二句，第二句正常出现且开头不丢。
- 连续说话不足 18 秒时，实时预览节奏不明显变慢。
- 收口识别失败时，主胶囊与最终缓存仍保留停顿前已有文本。
- Final ASR 开关关闭时，不因本功能偷偷调用完整录音识别。
- 主胶囊、生产缓存和最终粘贴仍然同源。

## Test Strategy

- 纯状态机测试：人声 → 1.1 秒停顿不收口；人声 → 1.2 秒停顿收口；停顿中恢复人声取消收口。
- 队列边界测试：收口快照不丢；普通快照在静音增长期间不继续入队。
- 合并测试：收口成功锁定新结果；收口失败锁定已有结果；下一块文本正确追加。
- 回归测试：Final ASR 开关、生产缓存、主胶囊订阅、停止排空逻辑保持不变。
