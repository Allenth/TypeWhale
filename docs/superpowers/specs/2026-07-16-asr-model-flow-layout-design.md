# ASR 模型按钮自适应平铺设计

## 目标

将“常用 → 状态”卡片中的 ASR 模型选择区从横向滚动改为自适应流式平铺。用户无需滚动即可看到全部模型，并可连续逐个切换测速。

## 交互与布局

- 模型按钮按照 `ASRBackend.allCases` 的既有顺序从左到右排列。
- 每个按钮按模型名称保留自然宽度，不强制等宽或固定列数。
- 当前行能容纳多少按钮就放多少；剩余宽度不足时，后续按钮整体换到下一行。
- 容器宽度变化时自动重新计算换行，不显示横向或纵向滚动条。
- 模型选择区高度随行数增长，状态卡片随内容自然增高。
- 保留现有按钮文字、选中态、禁用态、提示信息和无障碍标签。
- 保留现有切换进度条、切换失败回退和“下一次录音生效”语义。

## 行为边界

本轮只调整常用页模型按钮的布局容器，不修改：

- ASR 模型发现、完整性校验与运行环境校验；
- 模型切换、预热、失败恢复和持久化逻辑；
- 热词格式与各模型后端能力；
- 模型详情页和其他设置页。

## 验收标准

1. 常用页状态卡片内全部 ASR 模型按钮直接可见，不需要横向滚动。
2. 按钮宽度随标题变化，同一行尽可能利用可用空间，空间不足时完整换行。
3. 调整主窗口宽度后，按钮能重新换行且不重叠、不裁切、不越出卡片。
4. 可用模型可正常点击切换；不可用模型保持禁用并显示原有原因。
5. 选中态、切换进度、成功状态和失败回退与现有行为一致。
6. 真实安装版在当前默认窗口尺寸下排布清晰，模型名称可辨认。

## 验证方案

- 增加布局边界检查，确认选择器不再包含滚动视图，并具备按可用宽度换行的布局行为。
- 运行现有 ASR 模型选择、切换进度和后端边界检查。
- 完整 Swift 类型检查与应用构建。
- 覆盖安装到 `/Applications/TypeWhale Pro.app`，在真实安装版中截图复核默认窗口与改变窗口宽度后的布局，并点击至少一个非当前模型验证切换反馈。
