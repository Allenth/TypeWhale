# 候选胶囊退休与简洁黑色主题设计

**状态：** 已批准
**日期：** 2026-07-23
**目标：** 删除候选胶囊的独立产品形态，把已验证的黑色视觉风格迁移为主胶囊第三种主题；保留旁路作为测试与诊断工具。

## 1. 产品决定

- 正常产品流程只显示一个主胶囊。
- 主胶囊提供三种主题：默认胶囊、刘海主题、简洁黑色。
- 简洁黑色主题继承候选胶囊的黑色背景、轻描边和紧凑视觉，但不显示“候选”标签。
- 旁路胶囊继续保留，用于观察本地、MiMo 和豆包 Provider 的原始技术结果。
- 候选胶囊不再作为独立窗口、灰度产品视图或未来产品入口。

## 2. 架构边界

简洁黑色主题必须是主胶囊的纯展示实现：

```text
生产实时识别
→ ProductionRealtimePreviewDeliveryCache
→ 主胶囊状态投影
→ 简洁黑色主题 Presenter
```

它不得订阅 `ShadowTranscriptionRuntime`、`candidatePreviewRuntime` 或候选状态流，不得读取候选窗口的显示缓存。

旁路保持独立：

```text
本地 / MiMo / 豆包 Provider
→ ShadowTranscriptionRuntime
→ ShadowPreviewCoordinator
→ 旁路诊断胶囊
```

旁路失败、关闭或未配置 Key 时，不得影响主胶囊、最终交付、历史或粘贴。

## 3. 组件处理

### 新增

- `PreviewTheme` 增加简洁黑色主题枚举值。
- 新增独立主胶囊 Presenter，完整实现现有主胶囊展示协议。
- 设置页“预览主题”增加简洁黑色主题卡片。

### 删除

- 候选胶囊独立窗口和 Presenter。
- `CandidatePreviewCoordinator` 及其订阅、动画 Timer 和布局逻辑。
- `candidatePreviewRuntime` 及其创建、消费、完成和取消逻辑。
- 候选胶囊相关设置入口、诊断渲染日志和只服务于候选窗口的测试。
- 视觉中的“候选”标签和“等待候选结果”文案。

### 保留

- `ShadowPreviewCoordinator`、旁路窗口和旁路设置。
- 在线 ASR Provider、Key 设置、音频分发和旁路诊断日志。
- 候选实现中已经迁入通用层、且仍被主链路使用的 Reducer、状态投影和内容分层能力。
- 默认胶囊、刘海主题、闪念胶囊和 OpenClaw 的现有行为。

## 4. 简洁黑色主题行为

- 数据来源、稳定文字/可变尾巴、录音状态、检测状态、识别状态、错误状态和最终收尾与主胶囊保持一致。
- 主题只能改变绘制、尺寸、颜色、排版和主题自身的动效，不得修改文字、延迟数据、截断交付内容或决定最终粘贴来源。
- 不显示“候选”标签；主胶囊已有的必要产品状态和模式信息必须保留。
- 切换主题只影响下一次普通听写录音，沿用现有主题切换规则。
- 闪念胶囊和 OpenClaw 继续强制使用现有经典主题，本次不迁移。

## 5. 验收标准

1. 设置页可以在默认胶囊、刘海主题、简洁黑色之间选择，选中状态清楚。
2. 选择简洁黑色后，下一次普通录音只出现一个主胶囊。
3. 简洁黑色主题不出现“候选”标签，实时文字、稳定/可变状态、声波、录音与处理状态正常。
4. 打开旁路诊断后，只额外出现旁路胶囊，不再出现候选胶囊。
5. 关闭旁路后，主胶囊实时预览和最终粘贴保持正常。
6. MiMo、豆包或本地旁路故障不会改变主胶囊内容或最终粘贴。
7. 默认胶囊、刘海主题、闪念胶囊、OpenClaw、快捷键、翻译和最终交付无回归。

## 6. 禁止事项

- 禁止把 `CandidatePreviewView` 直接改名后接入主链路。
- 禁止保留隐藏的候选 runtime 或候选窗口作为简洁黑色主题的数据源。
- 禁止为了复用视觉而让 Presentation 层参与文本拼接、质量判断或最终交付。
- 禁止同时修改 ASR、缓存分块、Provider、Final ASR 或粘贴策略。

## 7. 迁移与回退

- 先新增简洁黑色主胶囊主题并验证完整状态，再删除候选窗口和 runtime。
- 每一步都保持默认主题与旁路诊断可用。
- 如简洁黑色主题验证失败，可回退到默认主题；不得恢复候选数据链路作为临时替代。
- 候选退休完成后，代码、测试、设置、日志和文档必须同步清理，不保留无主的 dormant path。
