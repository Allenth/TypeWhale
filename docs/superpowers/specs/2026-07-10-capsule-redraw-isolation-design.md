# 胶囊文字存在时的波形重绘隔离实验设计

**日期**：2026-07-10
**基线**：当前安装版 Build 652
**状态**：已确认，待实现

## 上位目标

本实验服务于更大的产品目标：让一次连续录音从前 `20s` 到 `60s`、数分钟及一小时以上都保持流畅、低延迟、连续和准确。波形重绘隔离只是第一个可回退的根因验证，不是完整解决方案；实验结果不能替代长录音体验、最终文本和资源占用的整体验收。

## 目标

验证一个已由当前代码直接确认的 UI 热点：胶囊已有文字后，波形数据更新仍使整颗 `RecordingCapsuleView` 失效并进入 `draw(_:)`，但此时 `draw(_:)` 并不绘制波形。第一阶段只消除这类无效文字胶囊重绘，观察长录音后段卡顿是否改善。

## 已确认事实

- `RecordingCapsuleView.update(bands:)` 当前会更新 `smoothedBands` 并设置 `needsDisplay = true`。
- `draw(_:)` 只有在 `textBuffer.isEmpty` 时才调用 `drawRecordingStatus`，已有文字时不会绘制波形。
- 文字更新仍需触发重绘；首段淡入和尾部推进仍需触发重绘。
- `RecordingPanel.updateBands(_:)` 只负责把波形数据交给胶囊，不参与识别、校准或最终输出。

## 实验行为

### 胶囊没有文字

保持现状：波形数据更新后触发重绘，录音状态文字和波形继续实时显示。

### 胶囊已有文字

波形数据继续写入 `smoothedBands`，但不再触发整颗文字胶囊的 `needsDisplay`。文字只有在以下事件发生时重绘：

- 新展示草稿到达；
- `CapsuleTextBuffer` 尾部推进；
- 淡入计时器刷新或结束；
- 状态、主题、边框、连接徽章等真实视觉属性变化。

## 明确不改动

- 不改变 ASR（语音识别）调用、模型、调度、校准窗口或 Reducer（状态归约器）。
- 不改变 `CapsuleTextBuffer` 的文字语义、首段淡入或 `75ms` 尾部推进。
- 不改变最终识别、智能整理、保存或粘贴链路。
- 不引入第二个模型，不调整线程优先级，不扩大窗口参数。
- 不改变无文字状态下的波形视觉表现。

## 实现边界

第一阶段只允许修改 `RecordingCapsuleView` 中波形更新导致的失效条件及其对应测试。不得顺手加入布局缓存、带样式文本缓存或 `RecordingPanel` 重构；这些属于第二阶段，必须基于本实验的采样结果单独确认。

## 验证方案

1. 先写一个失败测试，覆盖两个条件：无文字时 `bands` 更新请求重绘；有文字时 `bands` 更新不请求文字胶囊重绘。
2. 运行该测试确认它因当前无条件失效而失败。
3. 实现最小条件判断，让测试通过。
4. 运行相关单元测试和项目已有测试。
5. 使用唯一构建入口构建并覆盖安装新版本。
6. 手动录音对照：
   - 录音前 20 秒：确认首字、文字动画和波形行为不变；
   - 连续 60 秒：观察文字更新是否继续及时，是否出现跳字、丢字或窗口异常；
   - 连续 90 秒以上：观察后段卡顿是否减轻；
   - 停止后：确认最终识别、智能整理和粘贴结果与基线一致。
7. 通过 `sample` 或同等主线程采样确认：已有文字期间，`updateBands` 不再导致高频 `RecordingCapsuleView.draw`；若卡顿仍在，则记录为该实验未解决的问题，不在本轮继续叠加修改。

## 回退

实验失败时仅回退本次 `RecordingCapsuleView` 条件改动和对应测试；不触碰现有识别、校准和最终输出代码。构建前保留当前 Build 652 作为可比较基线。

## 成功标准

- 无文字状态的波形显示没有回归。
- 有文字状态的文字内容、动画和最终输出没有回归。
- 长录音后段主线程无效胶囊重绘次数下降；若用户体感没有改善，也必须保留采样证据并停止扩大本实验范围。
