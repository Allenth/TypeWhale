# 胶囊主题截图预览设计

## 目标

“预览主题”区域继续提供三种可选择主题，但把当前简化绘制的示意图升级为接近真实胶囊的截图式预览，让用户选择前就能看清实际效果。

## 展示内容

三张主题卡保持现有主题语义和选择行为：

1. **默认胶囊**
   - 在同一张预览卡中展示三种产品类型：
     - 普通录音胶囊
     - 闪念胶囊
     - OpenClaw 胶囊
   - 三种类型使用同一背景、统一比例和固定间距，便于直接比较颜色、标签、边框和波形。
2. **刘海主题**
   - 展示刘海主题的代表性录音状态。
3. **简洁黑色**
   - 展示简洁黑色主题的代表性文字预览状态。

## 实现边界

- 预览素材必须直接由当前生产 `RecordingPanel`、`NotchPreviewPresenter`、`MinimalBlackPreviewPresenter` 离屏渲染生成，禁止重新手绘或维护第二套胶囊视觉。
- 快照只使用固定演示状态，不读取或处理实时识别数据。
- 主题卡只负责显示、选中高亮和点击切换，不参与录音、ASR、缓存、粘贴或 OpenClaw 发送。
- 保留三种 `PreviewTheme` 枚举值及现有设置存储，避免主题选择行为发生变化。
- 默认胶囊卡可适当增加预览高度；主题区必须继续适配主窗口现有宽度，不产生横向溢出。
- 不修改生产胶囊、闪念胶囊、OpenClaw 胶囊本身的布局和动画。

## 验收标准

- “预览主题”区域同时展示默认胶囊、刘海主题、简洁黑色三张卡。
- 默认胶囊卡能看见普通、闪念、OpenClaw 三种类型，且没有裁切或互相遮挡。
- 截图与实际生产胶囊使用同一套尺寸、字体、标签、边框、波形和 OpenClaw 徽章；缩放后仍可辨认。
- 点击三张卡仍能正确切换主题，选中状态明显。
- 普通录音、闪念、OpenClaw、识别和粘贴链路行为不变。

## 测试

- 静态边界检查锁定三主题与默认主题三类型预览。
- 编译并覆盖安装后，截取真实主窗口“预览主题”区域。
- 逐一点击三张主题卡，确认选择状态和下一次录音的主题切换正常。
