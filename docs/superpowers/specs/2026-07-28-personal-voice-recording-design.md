# TypeWhale “我的声音”录制设计

日期：2026-07-28
状态：待产品负责人书面复核
适用范围：TypeWhale Pro 声音页、ZipVoice 本地参考音色

## 1. 产品目标

用户可以在“声音 → 朗读测试”中打开独立引导弹窗，录制一段自己的声音，并将它保存为唯一的本地 ZipVoice 参考音色“我的声音”。保存成功后，“我的声音”立即出现在朗读测试的音色下拉框中，可用于输入任意文字后的本地试听。

该能力只服务于单个个人参考音色，不扩展为录音管理器或多音色库。

## 2. 使用流程

1. 声音页在“播放”按钮旁增加“录制我的音色”入口。
2. 点击后打开独立 sheet，不改变声音页当前文字、模型和音色选择。
3. sheet 显示固定引导句：`清晰自然，稳定可靠。`
4. 用户点击“开始录音”，界面显示 0.8 秒倒计时，然后开始录音并显示实时波形；录音最长 3.0 秒，满时自动停止，用户在录满 1.0 秒后也可提前停止。
5. 录音停止后自动执行本地质量检查。
6. 检查通过后，用户可以：
   - 试听原始录音；
   - 使用这段录音生成固定测试句并试听克隆结果；
   - 重录；
   - 保存为“我的声音”。
7. 保存成功后 sheet 关闭，“我的声音”出现在音色下拉框中并自动选中。
8. 再次进入录音 sheet 并保存，会原子替换旧的“我的声音”；旧包只在新包完整通过校验后移入可恢复备份。

## 3. UI 与状态

采用已批准的 B 方案：引导式独立弹窗。

sheet 状态机：

- `idle`：显示引导句和“开始录音”。
- `countdown`：显示短倒计时，不写入参考文件。
- `recording`：显示波形、录音时长和“停止”。
- `validating`：检查格式、时长、响度和削波，禁用保存。
- `ready`：允许试听原音、试听克隆、重录和保存。
- `previewing`：播放原音或克隆结果，可停止。
- `saving`：原子写入正式参考包。
- `failed`：展示可执行错误，如“声音太短”“音量太小”“存在明显削波”“麦克风不可用”。

关闭 sheet 时必须停止录音、停止预览、释放麦克风并清理未保存的 staging 文件。

## 4. 录音与质量门禁

- 复用 TypeWhale 现有麦克风权限和输入设备选择，不新增第二套权限逻辑。
- 复用现有 `AudioRecorder` 捕获链路，但使用独立输出目录和独立任务 ID，不进入 ASR、听写、历史或粘贴流程。
- 现有捕获链路生成的音频使用系统原生 `AVAudioConverter` 转换为 ZipVoice 所需格式，不引入 Python、Conda、Homebrew 或 ffmpeg 运行时依赖。
- 正式参考包必须转换为：
  - 24 kHz；
  - 单声道；
  - PCM16 WAV；
  - 1–3 秒；
  - 非静音；
  - 明显削波比例不超过现有 ZipVoice 参考门禁。
- 不使用固定裁掉开头或结尾的方案。0.8 秒倒计时之后才启动捕获，录音窗口完整保留用户说出的首字与尾音。
- 引导文字与 `reference.txt` 固定一致，不允许用户编辑，避免音频/文字不对齐。
- 保存前必须用候选参考生成固定测试句并成功产出有效 WAV；用户试听是音色质量的最终门禁。

## 5. 本地存储

固定 voice ID：`zipvoice-my-voice`

正式目录：

`~/Library/Application Support/TypeWhale Pro/Models/tts/zipvoice-distill-int8-zh-en-emilia/references/zipvoice-my-voice/`

文件：

- `reference.wav`
- `reference.txt`
- `reference.json`

manifest 沿用现有 schema，并包含格式指标、音频哈希和文字哈希。所有文件只保存在本机，不上传、不进入日志、不写入朗读正文记录。

保存采用 staging → 完整校验 → 原子替换。失败时保留旧个人音色，不能留下半包或让下拉框指向损坏资源。

## 6. 音色发现与选择

- 现有四个预置音色保持静态、已验证且不变。
- “我的声音”是动态本地音色：只有正式目录存在且 manifest、格式和哈希全部有效时才进入声音页下拉框。
- 不把个人音色加入预置资格指纹，也不伪装成官方 4/4 资格结果。
- 个人音色损坏或被外部删除时 fail closed：从下拉框消失，不静默回退或覆盖其他音色。
- 本轮只接入声音页朗读测试。OpenClaw 个人音色选择、多个人声、重命名、导入、导出和云同步不在范围内。

## 7. 错误与隐私

- 麦克风未授权：展示系统设置入口，不创建文件。
- 输入设备断开：停止录音并提示重新录制。
- 时长、响度或削波不合格：保留临时录音供试听，但禁止保存，并明确说明重录方法。
- 克隆预览失败：禁止保存，不影响当前正式音色。
- 用户取消：删除 staging 和预览 WAV。
- 产品文案明确：“录音和克隆参考仅保存在这台 Mac，不会上传。”

## 8. 验收标准

1. 用户能从声音页打开独立录音 sheet，看到固定引导句。
2. 麦克风授权、拒绝、设备不可用和取消路径均有明确反馈。
3. 合格录音能试听原音和克隆测试音，且没有吞首字、串尾音或额外前缀。
4. 不合格录音不能保存，并准确显示失败原因。
5. 保存后“我的声音”立即出现在声音页音色下拉框并自动选中。
6. 重启 App 后“我的声音”仍存在且可用。
7. 重录保存原子覆盖旧个人音色；失败不破坏旧音色。
8. 删除或篡改参考文件后个人音色 fail closed。
9. 现有默认、Serena、CosyVoice 和视频参考音色的播放、资格与哈希不变。
10. 整个流程不上传录音，不写入 ASR 历史，不影响 Reader Demo、OpenClaw、听写、VAD 或智能改写。

## 9. 明确不做

- 多个个人音色；
- 自定义名称、头像或标签；
- 任意参考文字；
- 导入已有音频；
- 导出或分享参考包；
- 云端备份、同步或账户能力；
- OpenClaw 使用个人音色；
- 自动声纹识别或人物身份判断。
