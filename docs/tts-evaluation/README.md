# TypeWhale 本地 TTS 盲听评测

本目录定义候选模型的固定评测协议。当前八个模型都处于实验阶段；先比较听感，再比较资源，最后决定保留一到两个。

固定语料 ID：

- `zh-short-v1`：中文短句
- `en-short-v1`：英文短句
- `mixed-v1`：中英技术词混合
- `zh-long-v1`：日期、数字、标点和长段稳定性

每个可运行模型执行一次冷启动、三次热运行、一次长文本、一次取消、一次切换返回和一次断网重启。盲听文件只使用 `A`、`B` 等匿名标签；映射表保存在评测结果目录，不写入音频文件名。结果记录 sample ID、文本 SHA-256、字符数、运行时指纹、模型清单指纹和性能指标，不保存自由输入原文。

最终删除前必须先导出精确清理清单并由用户确认。Reader Demo、OpenClaw 语音链路、ASR/VAD 和智能整理不在清理范围内。
